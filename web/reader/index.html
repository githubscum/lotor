Verified means the bundle is unaltered and its signature matches the key fingerprint the bundle itself carries. That fingerprint is inside the bundle, so it names a signer only if you compare it with one you already trust. It does not mean the contents are correct. The signer's chain key sits unencrypted on their machine, so anyone holding that file can sign as them. The time is the signer's claim; the chain head only shows the bundle was signed after that entry existed.

  
This page is only as trustworthy as the copy of it you are running. Save it, check its hash, and run it offline.
